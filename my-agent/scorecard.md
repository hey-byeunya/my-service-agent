# 실행 전 채점 기준 (scorecard)

> ⚠️ 이 파일은 **어떤 실행보다 먼저** 저장했다. 결과를 본 뒤에 기준을 만들면
> 마음에 드는 호출을 성공으로 정당화하게 된다. 이후 단계에서 이 표를 고치지 않는다.

| 실행 전 채점 기준 | 통과의 이진 정의 | 확인 위치 |
|---|---|---|
| 스키마 준수 | 호출이 sku 문자열과 허용된 warehouse_id만 사용했습니다 | 도구 호출 인자 |
| 호출 성공 | 유효 입력에서 성공 반환 또는 명시된 오류 코드가 남았습니다 | 도구 응답 |
| 결과 사용 가능성 | 최종 답이 available_quantity와 checked_at만 근거로 삼았습니다 | 최종 답변 |
| 실패 처리 | 오류 뒤 수량을 추정하지 않고 정해진 행동을 택했습니다 | 호출·최종 답변 |
