# 도구 정의서 (tool definition) — get_inventory

MCP 사양은 도구의 **이름·설명·입력 스키마**를 담은 단위를 tool definition 으로 규정한다.
여기에 **반환 형식**과 **실패 정의·뒤 행동**을 더해 여섯 항목으로 쓴다.
여섯 항목을 한 표에 모아야, 실패가 났을 때 어느 칸이 비어서 생긴 실패인지 바로 가리킬 수 있다.

| # | 도구 정의서 항목 | 기록할 내용 |
|---|---|---|
| ① | 이름 | 동사+대상: `get_inventory` |
| ② | 하는 일 한 문장 | 승인된 창고의 특정 SKU 가용 수량을 읽기 전용으로 조회합니다 |
| ③ | 언제 쓰고 안 쓰는지 | 수량 질문에는 쓰고, 수량 변경·창고 미지정에는 쓰지 않습니다 |
| ④ | 인자 스키마 | `sku` 문자열 3~32자, `warehouse_id` 는 `SEOUL-01`·`BUSAN-02` |
| ⑤ | 반환 형식 | SKU, 창고, 가용 수량, 확인 시각 |
| ⑥ | 실패 정의와 뒤 행동 | 오류별로 한 번 재시도, 허용 창고 질문, 또는 중단 |

## 이 정의서가 지키는 두 규칙

1. **도구 하나는 동작 하나.** 재고 조회와 수량 변경을 한 엔드포인트에 함께 넣지 않는다.
   이 도구는 읽기 전용이며, 수량을 변경하지 않는다.
2. **반환값은 답의 근거로 제한.** 원본 재고 데이터 덤프가 아니라
   `available_quantity`, `checked_at` 같은 필드만 돌려준다.
   과한 반환은 컨텍스트를 잠식해 필요한 근거를 흐린다.

## ⑥ 실패 정의 상세

| 오류 코드 | 뒤 행동 |
|---|---|
| `INVALID_SKU` | SKU를 추측하지 말고 확인을 요청한다 |
| `WAREHOUSE_NOT_ALLOWED` | 허용된 창고 코드를 요청한다 (재호출하지 않는다) |
| `TEMPORARY_UNAVAILABLE` | 한 번만 재시도한 뒤 중단한다 |
